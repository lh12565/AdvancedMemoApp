# AdvancedMemoApp

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-sfueksh3)

Vibe coding project

AdvancedMemoApp is a comprehensive note-taking and journaling application that supports both standard memos and personal diary entries. It enables users to organize content with custom tags, set deadlines for tasks, attach location data, and easily share notes with others. The app provides built-in content statistics and automatically generates periodic reports.
